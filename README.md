InterviewIQ 🚀

InterviewIQ is an AI-powered mock interview platform designed to help candidates prepare for real-world technical and HR interviews.
The platform creates interactive interview sessions where an AI interviewer/virtual avatar asks questions based on the candidate’s selected job role, skills, and experience level — simulating the feel of an actual company interview process.

The goal of this project is to make interview preparation more practical, personalized, and confidence-building for students and job seekers.

💡 How It Works
User selects a job role or required skill set
The AI interviewer generates interview-style questions
Candidate responds during the interview session
The platform simulates a real interview environment for better preparation and confidence building

This helps users practice interviews in a more realistic and role-focused way instead of using static question lists.
